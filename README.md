# Time Changer Mod

Just one click and the time is changed. If you want to PvP at night on a server that is stuck on day, now that is possible.

## What it does

Time Changer Mod is a small Fabric client mod. Press one key and your client shows day or night. It stays locked until you press again. The server never sees it, so it works in singleplayer and on any server.

- Default key is O
- It toggles between Day and Night
- It is client only, so the server time is not changed
- It can be rebound in Options, then Controls, then Key Binds
